# Digital Notes Application (React + Vite)

## Run
    npm install
    npm run dev

## Structure
    src/
      components/  Navbar, NoteCard, NoteForm, SearchFilter
      pages/       NotesPage, NoteEditorPage, DashboardPage
      hooks/       useLocalStorage
      App.jsx      routes + add/update/delete handlers
      main.jsx     entry point

## Requirements
Node.js 18 or newer. Run all commands from inside this `digital-notes` folder (the one containing package.json).
